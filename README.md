# Technowp on Edge Delivery Services

Built on adobe/aem-boilerplate. Code only: content is authored in da.live.

## Blocks
hero, banner, columns, cards (variants: services, team, blog, projects), stats, portfolio (category filter),
pricing, testimonials, accordion, marquee, logos, contact-form (display only, not wired to a backend), header, footer.
Section styles (Section Metadata > Style): light, blue, center, tight.

## Content (da.live)
Pages: index, nav, footer. Block = table whose first row is the block name, e.g. `Cards (services)`.
Nav has 4 sections: logo | menu links | Get Quotes button | top bar. Footer: columns block, then copyright.
